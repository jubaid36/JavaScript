#  Minimalist Neon Digital Clock

A sleek, modern glassmorphic digital clock built with vanilla **HTML5**, **CSS3**, and **JavaScript**. Features real-time live clock updates and an interactive stop/resume toggle functionality.

---

##  Features
-  **Live Digital Clock:** Updates accurately every second.
-  **Pause & Resume Control:** Easily pause the clock and resume with a single click.
-  **Glassmorphism UI:** Modern dark mode styling with subtle ambient glow effects.
-  **Fully Responsive:** Looks crisp on mobile screens, tablets, and desktops.
- 0**Zero Dependencies:** Pure vanilla JavaScript and modern CSS.

---


##  Getting Started

1. Clone or download this repository:
   ```bash
   git clone https://github.com/your-username/clock-project.git
   ```
2. Navigate to the project directory:
   ```bash
   cd clock-project
   ```
3. Open `index.html` in any web browser.
