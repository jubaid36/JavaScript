# 📍 Geolocation Weather Fetcher

A lightweight JavaScript project demonstrating the use of the **Browser Geolocation API** combined with an **Asynchronous Fetch Request** to retrieve real-time weather and air-quality data from WeatherAPI.

## 🚀 Features

* **HTML5 Geolocation:** Seamlessly extracts user latitude and longitude via `navigator.geolocation`.

* **Async/Await API Integration:** Clean asynchronous requests querying the WeatherAPI endpoint.

* **Modern Minimal UI:** Centered, sleek dark-themed design with smooth glassmorphism and hover effects.

* **Zero Dependencies:** Pure Vanilla HTML, CSS, and JavaScript.


## 🔒 Security & Best Practices Note

> **Tip for Production:** Keep API keys private. In production applications, avoid committing sensitive API keys directly in client-side code by utilizing backend proxy servers or environment variables (`.env`).
